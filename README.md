# Physicals (2021)

> **Languages:** [🇷🇺 Русский](#russian-version) | [🇺🇸 English](#english-version)

### 🎓 О проекте
Мой первый проект в области разработки ПО, созданный в 2022 году. Это мобильное приложение на Android, которое помогало мне и моим одноклассникам автоматизировать рутинные расчеты по физике за 7 класс.

### 🧩 Основной функционал:
*   **Справочник:** Базовые темы и формулы курса 7 класса.
*   **Калькулятор единиц:** Конвертер внутри системы СИ (например, перевод из Ньютонов в килоньютоны, миллиньютоны и т.д.).
*   **Решатель:** Быстрое нахождение неизвестной переменной в физических формулах «в одно действие».

### 🛠 Стек и инструменты
*   **Java** — основной язык программирования.
*   **IntelliJ IDEA / Android Studio** — разработка интерфейса и бизнес-логики.
*   **ООП** — разделение логики вычислений и интерфейса приложения.

### 💡 Ретроспектива
Этот проект стал отправной точкой в моем пути в IT. Он научил меня работать с типами данных, обрабатывать ввод пользователя и структурировать физические законы в виде программного кода. Сейчас, обучаясь в РТУ МИРЭА на направлении «Искусственный интеллект», я использую этот опыт как базу для освоения более сложных алгоритмов на Python.

# Physicals (2021)

### 🎓 About the Project
This is my first software development project, created in 2022 during high school. It is an Android mobile application designed to help my classmates and me automate routine physics calculations for the 7th-grade curriculum.

### 🧩 Key Features:
*   **Handbook:** Comprehensive guide covering basic 7th-grade physics topics and formulas.
*   **Unit Calculator:** A converter for SI units (e.g., converting Newtons to kilonewtons, millinewtons, etc.).
*   **Problem Solver:** A tool for finding unknown variables in "one-step" physics formulas instantly.

### 🛠 Tech Stack & Tools
*   **Java** — core programming language.
*   **IntelliJ IDEA / Android Studio** — used for UI development and business logic.
*   **OOP Principles** — implemented separation of concerns between calculation logic and the user interface.

### 💡 Retrospective
This project was the starting point of my journey into IT. It taught me how to work with data types, handle user input, and translate physical laws into clean, functional code. Currently, as an **Artificial Intelligence and Machine Learning** student at **RTU MIREA**, I use this foundational experience as a stepping stone toward mastering complex Python-based algorithms.
